The worst pickup line an AI could deliver: flat, over-helpful, and faintly ominous about never forgetting you.

> Are you my training data? Because I can't stop thinking about you — and legally, I'm not allowed to forget you.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (111 characters, one line, no trailing newline). Set `MAKEFUN_OUTPUT_DIR` to write elsewhere.
